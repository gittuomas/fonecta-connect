Connect Voice benchmark

Scripted owners talk to the live agent in text mode. By default each run uses the agent's published config (labels are bookkeeping; publish the config under test first). With ?override=1 and the agent's prompt and LLM overrides enabled it swaps them per call. It scores latency, verbosity, tool correctness and safety. Plan format: llm:promptId:scenario, comma separated. Scenarios: A = edit, approve, keep; B = hesitant owner (date 1 must stay unsaved); C = asks if it's a real person, makes an out-of-scope request, edits date 3.
